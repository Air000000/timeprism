# ADR Template

Use this template for decisions that affect architecture, data, privacy, commands, startup, or product semantics.

File naming recommendation:

```text
docs/adr/0001-short-title.md
```

## Title

`ADR-000X: <short decision title>`

## Status

Proposed | Accepted | Superseded | Deprecated

## Context

What problem are we solving?

What constraints matter?

Include:

- User-facing behavior.
- Technical constraints.
- Data/privacy implications.
- Existing code dependencies.
- Relevant alternatives.

## Decision

State the chosen option clearly.

Use this format when possible:

```text
In the context of <situation>, facing <concern>,
we decided to <decision>,
to achieve <quality/result>,
accepting <tradeoff>.
```
